# Security Policy

## Reporting vulnerabilities

Please do not disclose a vulnerability in E2EESA validation logic or reference tooling through a public issue before coordinated review.

Until a dedicated disclosure channel is published, use GitHub's private vulnerability reporting feature if available for this repository.

## Scope

Security reports may concern:

- conformance validator bypasses;
- unsafe profile combinations accepted as compliant;
- downgrade or version-confusion weaknesses;
- malformed inputs that cause unsafe validation behavior;
- discrepancies between normative requirements and executable validation.

## Cryptographic scope

E2EESA does not authorize invention of new production cryptographic primitives. Experimental cryptographic research, if ever represented, must be isolated from production-recommended profiles and clearly labeled.
