# Reviewer-generated evidence

This directory is reserved for evidence generated by independent reviewers.

The repository does **not** contain pre-filled reviewer evidence.

Recommended command:

```bash
python review/run_expert_review_suite.py \
  --reviewer-id <reviewer-id> \
  --organization-id <organization-id> \
  --output review/evidence/<reviewer-id>-automated-evidence.json
```

The runner executes the reproducible automated portion of the review and writes a content-addressed JSON report.

Automated evidence is supporting material only. It does not replace the independent human review required by `review/EXPERT-REVIEW-GUIDE.md`, and it is not sufficient to make `review/validate_review.py --require-complete` pass.
